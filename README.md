# \# GoParking – Parking Allotment Management System

# 

# GoParking is a web-based Parking Lot Management System developed as a B.Tech CSE minor project. It helps manage parking slots and vehicle parking operations through a user-friendly interface.

# 

# \## Features

# 

# \- User registration and login

# \- Parking slot status and availability

# \- Vehicle parking and removal

# \- Vehicle and parking history management

# \- Parking dashboard and slot allocation

# \- Payment-related functionality

# \- Screenshots and project documentation

# 

# \## Technologies Used

# 

# \- \*\*Frontend:\*\* Streamlit

# \- \*\*Backend:\*\* Java and Python

# \- \*\*Database:\*\* SQLite

# \- \*\*Data Structures:\*\* TreeSet, HashMap, ArrayList

# \- \*\*Version Control:\*\* Git and GitHub

# 

# \## Data Structures Used

# 

# \- \*\*TreeSet:\*\* Helps organize and manage parking slot allocation.

# \- \*\*HashMap:\*\* Supports efficient lookup of parking-related information.

# \- \*\*ArrayList:\*\* Stores and manages collections of data.

# \## Installation and Setup

# 

# \### Prerequisites

# 

# Install Python, Java JDK, Git, and Visual Studio Code.

# 

# \### 1. Clone the repository

# 

# ```bash

# git clone https://github.com/Soumya-ranjandas/DSA-Project--GoParking.git

# cd DSA-Project--GoParking

# ```

# 

# \### 2. Install Python dependencies

# 

# ```bash

# python -m pip install -r requirements.txt

# ```

# 

# \### 3. Compile the Java backend

# 

# Open Command Prompt and navigate to the Java backend folder:

# 

# ```cmd

# cd java\_backend

# javac \*.java

# ```

# 

# \### 4. Run the application

# 

# Follow the project's configured Java backend and Streamlit startup procedure. The application may require environment variables for administrator setup and other configuration.
